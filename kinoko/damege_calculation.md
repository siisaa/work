# キノコ伝説 仲間ダメージ計算式

## 基本ダメージ

```
基本ダメージ = max(0, 攻撃力 - 防御力)
             × (仲間ダメージ% / 100)
             × (1 - 期待有効ダメ軽減% / 100)
```

## 期待有効ダメ軽減（鼓舞・抵抗を加味）

鼓舞と抵抗はそれぞれ独立して30%の確率で発動する。
4パターンの確率加重平均で期待値を算出する。

```
鼓舞効果% = 仲間鼓舞値 / 100   （例: 6000 → 60%）
抵抗効果% = 仲間抵抗値 / 100   （例: 6000 → 60%）

パターン           確率    有効軽減%の計算
鼓舞なし・抵抗なし  49%    基本軽減%
鼓舞あり・抵抗なし  21%    基本軽減% − 鼓舞効果%
鼓舞なし・抵抗あり  21%    基本軽減% + 抵抗効果%
鼓舞あり・抵抗あり   9%    基本軽減% − 鼓舞効果% + 抵抗効果%

各パターンの有効軽減%は clamp(計算値, 0%, 80%) で上限80%に制限する。
期待有効軽減% = 4パターンの確率加重平均
```

## 連撃乗数

```
有効連撃率 = max(0, 仲間連撃率% − 連撃無視%) / 100
連撃乗数   = 1 + 有効連撃率 × 1.0      ← 連撃は通常の+100%（2倍）
```

## 会心乗数

```
有効会心率   = max(0, 仲間会心率% − 会心無視%) / 100
会心実効倍率 = max(1.5, 会心ダメージ% / 会心抵抗%)   ← 下限150%
               ※ 会心抵抗%が未入力の場合は100として計算
会心乗数     = 1 + 有効会心率 × (会心実効倍率 − 1)
```

## 期待ダメージ（最終）

```
期待ダメージ = 基本ダメージ × 連撃乗数 × 会心乗数
```

## 補足

- 仲間ダメ軽減の上限: **80%**
- 会心ダメの下限: **150%**
- 仲間鼓舞: 発動時に相手の仲間ダメ軽減を鼓舞値/100(%)分だけ減らす
- 仲間抵抗: 発動時に相手の仲間ダメ軽減を抵抗値/100(%)分だけ増やす
- 連撃ダメージ: 通常攻撃と同じダメージをもう1回与える（+100%）
- 連撃でも会心は発動する
